# Infrastructure & Deployment

How Traineon is built, run locally, and deployed. **The UAT server runs the apps
natively on the host (no Docker for the apps)** — the API is a systemd service,
the web SPA is static files on S3 + CloudFront, and Postgres/Redis are host-native.
Only ClickHouse runs in a container.

> Source-of-truth precedence still applies (see `CLAUDE.md` / `docs/DEV_STRATEGY.md`).
> This doc covers infra + ops only. The `infra/docker/` compose files remain for
> **local dev backing services** and are no longer the deployment path.

---

## 1. Architecture (UAT)

```
   browser ─▶ CloudFront ─▶ S3 (private)        static SPA  (traineon.pentafox.in)
        │
        │  XHR/WS to API origin
        ▼
   nginx (TLS, Let's Encrypt)                    traineon-api.pentafox.in
        │  proxy_pass + WS upgrade
        ▼
   NestJS API  (systemd: traineon-api)           127.0.0.1:3000  (localhost only)
        │  REST /api/v1 · WS /api/v1/realtime/chat · in-process BullMQ worker
        ├──▶ Postgres 16   (host-native)         localhost:5432  db traineon_app
        ├──▶ Redis         (host-native)         localhost:6379  DB index /1
        └──▶ ClickHouse    (Docker container)    localhost:8123
```

- **Single API process:** `main.ts` does not branch on `APP_ROLE`, so REST + the
  realtime WS gateway + the BullMQ scoring worker all run in one Node process.
  `APP_ROLE` exists for a future split; until then run one `api`.
- **Conversation state** is durable in Postgres via LangGraph `PostgresSaver`
  (the `checkpoint*` tables — created at runtime, **not** Prisma-managed).
- **No MinIO / no S3 uploads** in this deployment. Text roleplay needs no object
  storage.

## 2. Repository layout

```
apps/api            NestJS backend (Prisma, LangChain/LangGraph, ws gateway) → dist/main.js
apps/web            React 19 + Vite SPA (TanStack Router/Query, Tailwind v4) → dist/
packages/contracts  Zod schemas shared by api + web (built to dist/ — build FIRST)
packages/tsconfig   Shared TS config
infra/docker/       docker-compose.services.yml (ClickHouse only in UAT; PG/Redis for local dev)
```

npm workspaces monorepo (root = repo root). Turborepo (turbo 2.x) drives builds;
it **requires** `"packageManager": "npm@10.8.2"` in the root `package.json` to
resolve workspaces.

## 3. Backend (API)

| | |
|---|---|
| Framework | NestJS (TypeScript) → compiled `apps/api/dist/main.js` |
| Runtime | Node 22, native on host (no Docker) |
| Port | `3000` — **localhost only**, not publicly exposed |
| Process manager | systemd — `/etc/systemd/system/traineon-api.service` |
| Env file | `~/learnium/apps/api/.env` |
| Public URL | `https://traineon-api.pentafox.in` (nginx reverse proxy + Let's Encrypt TLS) |
| Health | `GET /health`, `GET /ready` |
| WebSocket | via nginx upgrade headers (chat/roleplay) |

### Backing stores (UAT)

| Store | Where | Detail |
|---|---|---|
| PostgreSQL 16 | host-native | DB `traineon_app`, user `traineon`, `localhost:5432` |
| Redis | host-native | `localhost:6379`, **DB index `/1`** (DB `0` used by another app) |
| ClickHouse | Docker (`traineon-clickhouse`) | `localhost:8123` |

`.env` connection values:
```
DATABASE_URL=postgresql://traineon:<pass>@localhost:5432/traineon_app
REDIS_URL=redis://localhost:6379/1
CLICKHOUSE_URL=http://localhost:8123
```

### systemd

```bash
sudo systemctl restart traineon-api
sudo systemctl status  traineon-api
journalctl -u traineon-api -f
```

## 5. Deploy / update sequence

Run on the server, from the repo root, for the branch being deployed.

```bash
cd ~/learnium
git fetch origin
git checkout <branch>
git pull origin <branch>

npm install

# ── Backend ──────────────────────────────────────────────
npm run build --workspace=packages/contracts   # contracts FIRST (api + web depend on it)
cd apps/api
npx prisma generate
npx prisma migrate deploy                       # idempotent; applies un-applied migrations
npm run build                                   # nest build → dist/main.js
npx prisma db seed        # only if seed data changed
npm run seed:llm          # only if the LLM registry changed
sudo systemctl restart traineon-api
curl http://127.0.0.1:3000/ready                # expect 200

# ── Frontend ─────────────────────────────────────────────
cd ~/learnium/apps/web
npx vite build                                  # primes routeTree.gen.ts if missing
cd ~/learnium
npm run build --workspace=apps/web
aws s3 sync apps/web/dist s3://traineon-frontend-pentafox --delete
aws cloudfront create-invalidation --distribution-id <DIST_ID> --paths "/*"
```

- `git pull` may fail if the remote branch history was rewritten (e.g. a secret
  purge). Recover with `git fetch origin && git reset --hard origin/<branch>`.
- `npm install` at the root installs every workspace; the `@langchain/core`
  override in the root `package.json` dedupes the LangChain type tree — do a clean
  `rm -rf node_modules && npm install` if a `nest build` TS2375 appears.

## 6. Required environment (api)

From `apps/api/src/core/config/env.schema.ts`. **Required (no default):**

| Var | Notes |
|-----|-------|
| `DATABASE_URL` | Postgres connection string (native `localhost:5432`) |
| `REDIS_URL` | Redis connection string — **include the `/1` DB index** |
| `CLICKHOUSE_URL` | ClickHouse HTTP endpoint (`http://localhost:8123`) |
| `JWT_ACCESS_SECRET` | ≥ 32 chars |
| `JWT_REFRESH_SECRET` | ≥ 32 chars |
| `CREDENTIAL_ENCRYPTION_KEY` | ≥ 32 chars — **AES-256-GCM key for BYOK provider keys.** Back it up; changing it invalidates every stored provider credential. |

Useful optional: `APP_ROLE`, `CORS_ORIGINS` (set to `https://traineon.pentafox.in`),
`LOG_LEVEL`, `SESSION_IDLE_TIMEOUT_MINUTES`, `WORKER_CONCURRENCY`,
`LANGSMITH_*` (tracing — off by default; **never commit real keys**). Full list in
the schema.

> Secrets live only in `~/learnium/apps/api/.env` (git-ignored). **Do not commit
> `.env`**; `.env.example` must carry placeholders only.

## 7. TLS / nginx

nginx on the host terminates HTTPS (Let's Encrypt) for `traineon-api.pentafox.in`
and reverse-proxies to `127.0.0.1:3000`, forwarding the **WebSocket upgrade**
(`Upgrade` / `Connection` headers, long `proxy_read_timeout` for the chat socket).
The frontend origin (`traineon.pentafox.in`) is served by CloudFront over TLS.

Set `CORS_ORIGINS=https://traineon.pentafox.in` since the SPA and API are on
**different** origins here (unlike the old same-origin nginx setup).

## 8. Database & migrations

- **Schema**: Prisma, `apps/api/prisma/schema.prisma`. App DB = `traineon_app`
  on the host-native Postgres 16.
- **Apply**: `npx prisma migrate deploy` (only un-applied migrations, idempotent).
  Run it in the deploy sequence *before* restarting the service.
- **Seed** (`prisma db seed`, `seed:llm`) — one-time / on data changes. Seeds use
  `ts-node` against `src`, so run from the repo checkout (the compiled `dist` has
  no seed source).
- **Checkpoint tables** (`checkpoints`, `checkpoint_writes`, …) are created by
  LangGraph at runtime, not Prisma-managed — they reappear on the first roleplay.

## 9. LLM keys

- Provider API keys are **encrypted in Postgres** (AES-256-GCM), **not in `.env`**.
- Added via the admin UI: **LLM Ops → Providers** after login.
- Default admin: `admin` / `Admin@123` — **change after first login**.
- Seeded providers: OpenAI, Google Gemini. Seeded chat models: `gpt-4o-mini`,
  `gpt-4o`, `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-2.5-pro`
  (plus voice models). Re-run `npm run seed:llm` after registry changes — it prunes
  stale catalog rows and syncs pricing to configured models.

## 10. Other apps on the same server

- `~/consent-management-platform/` — separate app, managed by **PM2**, port `8000`,
  uses Redis **DB 0**.
- Both apps share the same **PostgreSQL** instance and the same native **Redis**,
  isolated by separate DBs (Traineon = Redis DB `1`; consent app = DB `0`).
  Keep the `/1` suffix in `REDIS_URL` or the two apps will collide.

## 11. Local development

Run backing services in Docker, the API + web on the host:

```bash
# 1. backing services (local only)
cd infra/docker
docker compose up -d postgres redis clickhouse
docker compose ps

# 2. API
cd ../../apps/api
cp .env.example .env
npx prisma migrate deploy       # or: npx prisma migrate reset --force (drops + seeds)
npx prisma db seed              # roles, admin, sample personas, test users
npm run seed:llm                # OpenAI + Gemini providers/models (NO keys)
cd ../../
npm run dev --workspace=apps/api    # http://localhost:3000

# 3. Web
npm run dev --workspace=apps/web    # http://localhost:5173
```

Default logins after seed: `admin / Admin@123`, `trainer1|trainer2 / Trainer@123`,
`trainee1..4 / Trainee@123`. Add provider keys via **LLM Ops → Providers** (BYOK).

## 12. Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| API won't start | check the service log | `journalctl -u traineon-api -n 100 --no-pager` |
| `nest build` **TS2375** (`_separateRunnableConfigFromCallOptionsCompat`) | duplicate `@langchain/core` copies from a drifted install | `rm -rf node_modules && npm install` (root override dedupes) |
| `git pull` rejected / diverged | remote history was rewritten | `git fetch origin && git reset --hard origin/<branch>` |
| `ioredis ECONNREFUSED 127.0.0.1:6379` | native Redis down | `sudo systemctl status redis-server` |
| Traineon reads the other app's cache | `REDIS_URL` missing the `/1` DB index | append `/1` to `REDIS_URL`, restart |
| Prisma **P3005** schema not empty | tables exist but no `_prisma_migrations` | baseline, or on a throwaway DB `prisma migrate reset --force` |
| Web shows mock data | `VITE_ENABLE_MOCKS` not `false` at build | rebuild with `VITE_ENABLE_MOCKS=false`, re-sync to S3 |
| WebSocket won't connect | nginx not forwarding `Upgrade`/`Connection` | fix the api vhost WS headers, `sudo nginx -t && sudo systemctl reload nginx` |
| SPA route 404 on refresh | CloudFront not falling back to `index.html` | set the 403/404 → `/index.html` (200) error responses on the distribution |
| Stale frontend after deploy | CloudFront cache | `aws cloudfront create-invalidation --distribution-id <DIST_ID> --paths "/*"` |

Inspect the DB:
```bash
psql -U traineon -d traineon_app -h localhost -c "\dt"
```
